========================================
STEP 1: 全体像
========================================
▼処理フロー
1. account.php → 「アイコンを変更」リンク
2. edit-icon.php → 丸いアイコンプレビュー表示
3. アイコンをクリック → ファイル選択
4. 選択後 → 自動送信 → exec_icon_upload.php
5. バリデーション → 一時保存（{user_id}_temp.拡張子）→ edit-icon.phpへ
6. プレビュー確認 → 以下3つのボタン
   A. 保存 → exec_edit-icon.php → 一時→本番 → DB更新
   B. キャンセル → exec_icon_cancel.php → 一時削除
   C. デフォルトに戻す → exec_icon_reset.php → 本番削除、DB NULL

========================================
STEP 2: 準備（DB、ディレクトリ、セキュリティ）
========================================
▼DB
ALTER TABLE users ADD COLUMN icon VARCHAR(255) NULL;

▼ディレクトリと画像
1. public/image/icon/ 作成
2. public/image/icon/default.png 配置

========================================
STEP 3: 基礎的な関数（ファイル・DB操作）
========================================
▼src/functions/icon-file.php - アイコンファイルの操作（保存、削除、パス取得など）
▼src/functions/db.php - DBのアイコンカラムの更新・取得

========================================
STEP 4: バリデーション
========================================
▼src/functions/validation.php - 汎用的な画像バリデーション関数
▼src/functions/validation-error.php - アイコン専用のバリデーション

========================================
STEP 5: アイコン管理・表示
========================================
▼src/functions/icon.php - アイコンの保存・削除・更新
▼src/functions/display_icon.php - アイコンの表示

========================================
STEP 6: 画面
========================================
▼src/template/edit-icon_template.php - アイコン編集画面
▼src/template/account_template.php - アイコン項目追加（既存に追記）

========================================
STEP 7: 処理実行
========================================
▼public/account-edit/edit-icon.php - 編集画面表示
▼public/account-edit/exec_icon_upload.php - 一時保存
▼public/account-edit/exec_edit-icon.php - 確定
▼public/account-edit/exec_icon_cancel.php - キャンセル
▼public/account-edit/exec_icon_reset.php - リセット
