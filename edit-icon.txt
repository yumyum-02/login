▼処理フロー
1. account.php → 「アイコンを変更」リンク
2. edit-icon.php（編集画面）→ 丸い形のアイコンプレビュー表示
3. アイコンをホバー → 半透明オーバーレイと鉛筆アイコン表示
4. アイコンをクリック → ファイル選択ダイアログ
5. ファイル選択後 → 自動的にフォーム送信 → exec_icon_upload.php
6. バリデーション → 一時保存（{user_id}_temp.拡張子）→ edit-icon.phpにリダイレクト
7. edit-icon.php → 丸い形で一時保存画像をプレビュー表示
8-A. 変更を保存ボタン → exec_edit-icon.php → 一時ファイル→本番ファイル → DB更新 → account.phpへ
8-B. キャンセルボタン → exec_icon_cancel.php → 一時ファイル削除 → account.phpへ
8-C. デフォルトに戻すボタン → exec_icon_reset.php → 本番ファイル削除 → DB NULL → account.phpへ

【バリデーション】
▼src/functions/validation.php に追加する汎用的な画像バリデーション関数
・isImageUploaded($file)
→ファイルがアップロードされているかチェック
→!isset($file) || $file['error'] === UPLOAD_ERR_NO_FILE をチェック
→true/false を返す

・isValidImageFileSize($file, $maxSizeInBytes)
→ファイルサイズが指定されたバイト数以下かチェック
→$file['size'] <= $maxSizeInBytes を判定
→true/false を返す

・isValidImageDimensions($file, $maxWidth, $maxHeight)
→getimagesize()で画像の幅と高さを取得
→幅が$maxWidth以下、高さが$maxHeight以下かチェック
→true/false を返す

・isValidImageMimeType($file, $allowedMimeTypes)
→getimagesize()でMIMEタイプを取得
→$allowedMimeTypes配列に含まれているかチェック
→true/false を返す

【アイコンのバリデーションをまとめた関数】
▼src/functions/validation-error.php に追加する関数
・アイコンの変更画面で「変更を保存」を押した時に発動する
・getIconValidationErrors($file)
→アイコンのバリデーションを実行してエラー配列を返す
→!isImageUploaded($file) なら ['画像がアップロードされていません'] を返して終了（画像を選択せずに保存ボタンを押した時）
→$errors = [] を初期化
→$file['error'] !== UPLOAD_ERR_OK ならエラー追加: 「画像のアップロードに失敗しました」
→getimagesize($file['tmp_name']) でファイルが画像か確認、falseならエラー追加: 「有効な画像ファイルではありません」
→!isValidImageFileSize($file, 1024 * 1024) ならエラー追加: 「容量は1MB以下の画像をアップロードしてください」
→!isValidImageMimeType($file, ['image/jpeg', 'image/png']) ならエラー追加: 「PNG または JPEG 形式の画像をアップロードしてください」
→!isValidImageDimensions($file, 400, 400) ならエラー追加: 「画像サイズは400px × 400px以下にしてください」
→$errors を返す

【アイコンの表示（汎用）】
▼src/functions/display_icon.php に追加する関数（表示用）
・getIconPath($userId)
→DBからiconカラムを取得
→iconがNULLまたは空ならデフォルト画像のパスを返す
→ファイルが存在しなければデフォルト画像のパスを返す
→それ以外はユーザーの画像パスを返す

・displayIcon($userId, $size = 100, $class = '', $alt = 'アイコン')
→getIconPath()でアイコンのパスを取得
→imgタグを生成して返す
→例: <img src="/image/icon/123.jpg" width="100" height="100" class="" alt="アイコン">
→いろんなページで簡単にアイコンを表示できる

【アイコンの保存・削除・DB更新を管理】
▼src/functions/icon.php に追加する関数
・saveTempIcon($userId, $file)
→MIMEタイプから拡張子を決定（png または jpg）
→一時ファイル名を生成: {user_id}_temp.{拡張子}（例: 123_temp.jpg）
→保存先ディレクトリが存在しなければ作成
→既存の一時ファイルがあれば削除（拡張子が異なる可能性があるため）
→move_uploaded_file()で一時ファイルとして保存
→保存した一時ファイル名を返す

・confirmIcon($userId)
→セッションから一時ファイル名を取得
→一時ファイルが存在しなければエラー
→既存の本番ファイルを削除（{user_id}.jpg, {user_id}.pngなど）
→一時ファイルを本番ファイルにリネーム（{user_id}_temp.jpg → {user_id}.jpg）
→本番ファイル名を返す

・deleteTempIconFile($userId)
→jpg, jpeg, png の拡張子で一時ファイル（{user_id}_temp.*）が存在するかチェック
→存在すればunlink()で削除

・deleteIconFile($userId)
→jpg, jpeg, png の拡張子で本番ファイル（{user_id}.*）が存在するかチェック
→存在すればunlink()で削除

・updateUserIcon($userId, $filename)
→UPDATE users SET icon = :icon WHERE id = :id を実行

・resetIcon($userId)
→deleteIconFile()で本番ファイルを削除
→updateUserIcon()でDBをNULLに更新

【アイコンのアップロード処理（一時保存）】

【アイコンの変更確定】

【セキュリティ対策】
▼public/image/icon/.htaccess を作成【重要度：最高 🔴 必須】
・php_flag engine off でPHP実行を無効化（RCE攻撃対策）
・Options -Indexes でディレクトリリスティングを無効化
・画像ファイル（jpg, jpeg, png）のみアクセス許可

▼src/functions/validation.php に追加【重要度：高 🟡】
・isValidImageMimeTypeStrict($file, $allowedMimeTypes)
→ finfo_file() と getimagesize() の二重チェックでMIMEタイプを厳密に検証
→ ファイルタイプ偽装を防ぐ

▼src/functions/icon.php の saveTempIcon() と confirmIcon() に追加【重要度：高 🟡】
・ファイル保存後に chmod($path, 0644) でパーミッション設定
→ ファイルが実行可能にならないようにする

▼src/functions/icon.php に追加【重要度：中 🟢 推奨】
・reencodeImage($sourcePath, $destPath, $mimeType)
→ GDライブラリで画像を読み込んで再保存
→ EXIFデータや埋め込まれた不正コードを除去
→ saveTempIcon() と confirmIcon() で使用

▼src/functions/validation-error.php の getIconValidationErrors() を修正【重要度：高 🟡】
・isValidImageMimeType() の代わりに isValidImageMimeTypeStrict() を使用
→ より厳密なMIMEタイプ検証
